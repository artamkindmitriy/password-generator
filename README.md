# 🔐 Password Generator

> Консольное ООП-приложение на Python для быстрой и безопасной генерации надежных паролей с валидацией длины и выбором параметров.

---

## ✨ Основные возможности (Features)
* **Безопасная генерация:** использование встроенного криптографического модуля `secrets` вместо псевдослучайного `random`.
* **Валидация данных:** строгий контроль длины пароля через свойства и сеттеры (`@property`), исключающий некорректный ввод (отрицательные числа, нули или буквы).
* **Гибкая настройка:** возможность включать или отключать цифры и спецсимволы в конфигурации.
* **Интерактивное консольное меню:** простое и понятное управление программой через терминал.

---

## 🛠️ Архитектура и стек
* **Язык:** Python (версия 3.x)
* **Парадигма:** Объектно-ориентированное программирование (ООП)
* **Библиотеки:** `secrets`, `string`

---

## 📂 Описание структуры класса `PasswordGenerator`

* `__init__(self, length, use_digits, use_symbols)` — инициализация базовой конфигурации объекта.
* `length (property & setter)` — безопасный контроль длины пароля (выброс `ValueError` при выходе за допустимые границы или неверном типе данных).
* `generate(self)` — сборка пула доступных символов и генерация случайной строки заданной длины.
* `run(self)` — главный цикл интерактивного консольного меню.
